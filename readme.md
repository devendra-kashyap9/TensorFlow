# TensorFlow Basic Practices

A **starter repository** for TensorFlow best practices, covering project structure, coding standards, and deployment basics.

---

## 📌 About

This repository provides **guidelines, templates, and examples** for working with TensorFlow in a **collaborative, maintainable, and scalable** way. It includes:

- **Project structure** for ML experiments
- **Coding standards** (PEP 8, type hints, docstrings)
- **Data handling** (TFRecords, `tf.data`)
- **Model training** (Keras, custom loops)
- **Evaluation & logging** (TensorBoard, metrics)
